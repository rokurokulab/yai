# Changelog

All notable changes to yai are documented here. Format follows [Conventional Commits](https://www.conventionalcommits.org/); releases are auto-generated by [git-cliff](https://git-cliff.org).

## [0.1.0] - 2026-04-23

Initial release. Agent loop harness with codex adapter.

### Features

- Tool-agnostic core loop: story queue → execute → semantic eval → (fix rounds) → pass → next story
- Final phase: run-level PRD review (`final_eval`) with bounded corrective rounds (`final_fix`)
- Codex adapter (`scripts/adapters/codex.sh`): invokes `codex exec`, retry/timeout policy, transport-failure classification, per-attempt event logging
- 4 prompt templates: `EXECUTE.md`, `EVAL.md`, `FINAL_EVAL.md`, `FINAL_FIX.md`
- Full state persistence in `.yai/`: prd.json, prd-source.md, progress.txt, completed-stories.json, active-story.json, per-run artifacts, archive snapshots
- Checkpoint / resume via `--adopt-dirty-worktree` flag
- Artifact validation + normalization for every phase (execution, eval, final-eval, final-fix)
- Integration test suite (`test/semantic-eval.sh`, 11 scenarios) using embedded mock codex — no real tool or network calls

### Configuration

- ~20 `YAI_*` environment variables covering sandbox, approval, model, profile, timeout, retry budgets, fix-round limits — per-purpose (execute / eval / final-eval) tuning

### CI / release

- `ci.yml` — hawkeye license-header + shellcheck + JSON/YAML validation
- `smoke-test.yml` — full 11-scenario suite on every PR + push to main
- `cd.yml` — tag-triggered git-cliff CHANGELOG + GitHub Release
- `pr-check-ci.yml` — conventional-commits PR title gate
